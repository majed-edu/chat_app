# تطبيق دردشة باستخدام Flutter

تطبيق دردشة بسيط للتعلّم، يتيح كتابة الرسائل وإرسالها وعرضها داخل واجهة سهلة.

## التقنيات

- **Flutter** لواجهة التطبيق.
- **Dart** للبرمجة.

## التشغيل

```bash
flutter pub get
flutter run
```

## الهدف

التدرّب على بناء واجهات Flutter وإدارة إدخال المستخدم وعرض الرسائل.
